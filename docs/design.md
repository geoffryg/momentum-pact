# Design direction

Momentum Pact is built around **serene obligation**: commitments remain honest,
visible, and actionable without using shame, surveillance, or constant urgency.

Its workflow follows CCCER:

1. **Capture** obligations from direct entry and, eventually, trusted sources.
2. **Clarify** the related goal, subtasks, and observable completion criteria.
3. **Commit** to a due time and useful intermediate check-ins.
4. **Execute** one concrete criterion at a time.
5. **Review** what happened, preserve history, and revise deliberately.

The interface should stay quieter than the information it contains. Semantic
colors signal genuine state changes; optional metadata and integrations should
not compete with the next visible action.
